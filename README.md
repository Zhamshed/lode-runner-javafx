# Lode Runner JavaFX

A simple 2D game inspired by the classic **Lode Runner**, developed in Java using JavaFX.

The player navigates through the level, collects gold, uses ladders, avoids guards, and reaches the portal to complete the game.

## Features

- Player movement and gravity
- Ladder climbing
- Gold collection system
- Enemy guards
- Digging mechanics
- Block restoration
- Portal and level completion
- Gold counter
- JavaFX graphical interface

## Controls

| Key | Action |
|-----|--------|
| ← | Move left |
| → | Move right |
| ↑ | Climb up |
| ↓ | Climb down |
| Q | Dig left |
| E | Dig right |

## Technologies

- Java
- JavaFX
- FXML
- Maven

## Requirements

- Java 17 or newer
- Maven or Maven Wrapper

## Running the project

### macOS / Linux

```bash
./mvnw clean javafx:run
```

### Windows

```powershell
.\mvnw.cmd clean javafx:run
```


## About

This project was created as a Java programming project and demonstrates object-oriented programming, JavaFX UI development, event handling, collision detection, and basic game logic.
